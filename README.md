# 🚀 GitHub Profile Card

A simple and stylish web app that allows users to search for any GitHub profile and display basic user details like avatar, name, bio, and followers.

---

## 📖 Description

This project uses the GitHub API to fetch user data dynamically and display it in a modern glassmorphism UI card. It is built using pure HTML, CSS, and JavaScript.

---

## ✨ Features

- 🔍 Search any GitHub username
- 👤 Display profile avatar
- 📝 Show name and bio
- 👥 Followers count
- ⚡ Real-time API fetching
- ⌨️ Enter key support
- ❌ Error handling (User not found)
- 🔄 Loading state indicator
- 💎 Modern glass UI design

---

## 🛠️ Tech Stack

- HTML5
- CSS3 (Glassmorphism UI)
- JavaScript (ES6)
- GitHub API

---

## ⚙️ How It Works

1. User enters a GitHub username
2. App sends request to GitHub API:
   https://api.github.com/users/{username}
3. Data is fetched using `fetch()`
4. UI updates with user information

# 🚀 GitHub User Card (XMLHttpRequest)

A simple web project that fetches GitHub user data using XMLHttpRequest and displays it in a clean UI card.

---

## 📖 Description

This project demonstrates how to use **XMLHttpRequest (AJAX)** to fetch data from the GitHub API and dynamically create a user profile card using JavaScript.

It displays basic user information like profile image, name, and followers count.

---

## ✨ Features

- 🌐 Fetch data from GitHub API
- 👤 Display user profile image
- 📝 Show user name
- 👥 Followers count
- ⚡ Uses XMLHttpRequest (AJAX)
- 🎯 Pure JavaScript DOM manipulation
- 💎 Clean and minimal UI design

---

## 🛠️ Tech Stack

- HTML5
- CSS3 (inline styling)
- JavaScript (ES6)
- XMLHttpRequest (AJAX)

---

## ⚙️ How It Works

1. API request is sent to:
   https://api.github.com/users/hiteshchoudhary

2. XMLHttpRequest fetches the data

3. When `readyState === 4`, response is received

4. JSON data is parsed

5. DOM elements are created dynamically:
   - Image
   - Name
   - Followers

6. Card is displayed on screen
